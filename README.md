# RoutineX — Minimalist Daily Routine & Task Tracker ⚡

**RoutineX** is a 100% minimalist, clean, and distraction-free single-page web application for personal routine management, daily task tracking, and time discipline.

Built with **Next.js (App Router)**, **Tailwind CSS**, and **Lucide React**.

---

## ✨ Features

- **Minimalist & Distraction-Free UI**: Clean typography, elegant dark/light theme, and refined aesthetics inspired by Notion and Things 3.
- **Pre-Loaded Daily Routine**:
  - **Fajar Block**: 1 Hour (Wazu/Nahana + 4 Rakat Namaz + 20 mins Quran Reading)
  - **Foodpanda Rider Work**: 6 Hours daily
  - **YouTube Channels Creation**: 4 Hours daily (Drama & Cartoon/Fruit Drama)
  - **Prayers (5 Daily)**: Zuhar (45m), Asar (25m), Maghrib (25m), Isha (45m), Fajar
  - **Web Dev Agency & Client Work / Projects**: 2 Hours
  - **Personal Growth & Skills**: Daily exercise/workout, 20 mins skill learning, and night reading before sleep
- **Full CRUD Capabilities**:
  - **Add**: Quick inline task creator with duration and category tags.
  - **Check/Uncheck**: Instant check off with strikethrough feedback.
  - **Delete**: Remove any task with one click.
  - **Reset Day**: Uncheck all items for a fresh day with one tap.
  - **Restore Defaults**: Easily reset to the original master routine anytime.
- **100% Offline & LocalStorage Persistence**:
  - Fully functional without an internet connection.
  - Automatically persists all state across browser sessions and device refreshes.
- **Progress Counter**:
  - Real-time "Completed X of Y tasks" counter with a slim, subtle progress bar.

## 🚀 Getting Started

### Prerequisites
- Node.js (v18.17+ or LTS v24+)
- npm or yarn

### Installation

```bash
# Clone the repository
git clone https://github.com/actorsbiography82-byte/RoutineX.git

# Navigate into the directory
cd RoutineX

# Install dependencies
npm install

# Start development server
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.

### Production Build

```bash
npm run build
npm run start
```
